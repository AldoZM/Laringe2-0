ARQUITECTURA ELEGIDA (Opcion C — validada)
Split de responsabilidades:

ESP32:
  - Recibe senal del laringofono via circuito acondicionamiento
  - ADC 12-bit @ 8-16kHz sampling rate
  - Buffer circular de frames (512-1024 muestras)
  - Envia frames por USB Serial (CDC) a RPi 5

Raspberry Pi 5:
  - Recibe frames en Python
  - Preprocesa: MFCC (13-26 coeficientes) via librosa
  - Inferencia: TFLite o ONNX — clasifica fonema (~44 clases ingles)
  - Post-proceso: decodificador CTC o buffer fonemas -> palabra
  - TTS: Piper TTS (neural, calidad alta) -> audio WAV
  - Reproduce por bocina via PyAudio / aplay

Bocina:
  - Salida audio jack 3.5mm RPi 5
  - Amp clase D PAM8403 ~$30 MXN
  - Bocina 8ohm 0.5W

Comunicacion ESP32 <-> RPi 5: USB Serial (CDC)
Fase futura: Bluetooth a celular

CIRCUITO ACONDICIONAMIENTO DE SENAL (COMPLETO)

Funcion: preparar senal analogica del laringofono para ADC del ESP32.
SIN este circuito: voltaje negativo daña pin ADC ESP32 permanentemente.

ETAPAS:
1. Acoplamiento AC (C1: 10uF) — bloquea voltaje DC negativo del laringofono
2. Divisor de voltaje bias (R1+R2: 10kOhm c/u) — crea referencia 1.65V (VCC/2)
   Señal se monta sobre 1.65V -> nunca baja de 0V -> pin seguro
3. Amplificador no-inversor (LM358) — ganancia 40x (señal ~10mV -> ~400mV)
   Gain = 1 + Rf/Rin = 1 + 390k/10k = 40
4. Filtro RC anti-aliasing (Rout: 1kOhm + Cout: 47nF) — corta frecuencias >3.4kHz
   Si muestreamos a 8kHz, Nyquist=4kHz, fc=3.4kHz evita aliasing

DIAGRAMA DE CONEXIONES (breadboard):
  1. Baofeng MIC+ -> C1 (10uF) -> nodo central
  2. Nodo central -> R1 (10kOhm) -> 3.3V pin ESP32
  3. Nodo central -> R2 (10kOhm) -> GND
  4. Nodo central -> pin 3 LM358 (+)
  5. LM358 pin 8 (VCC) -> 3.3V
  6. LM358 pin 4 (GND) -> GND
  7. LM358 pin 1 (OUT) -> pin 2 (-) via Rf (390kOhm) [feedback]
  8. Pin 2 (-) -> GND via Rin (10kOhm)
  9. LM358 pin 1 (OUT) -> Rout (1kOhm) -> GPIO34 ESP32 ADC
  10. GPIO34 -> Cout (47nF) -> GND

CONCEPTOS CLAVE EXPLICADOS:
- Circuito acondicionamiento: prepara señal analogica cruda para MCU
  Sin el -> señal debil, voltaje negativo daña ADC, ruido inutilizable
- C1 (acoplamiento AC): bloquea DC negativo, pasa solo AC (la vibracion)
- R1+R2 (bias): crean 1.65V para centrar señal -> pin ADC nunca ve negativo
- LM358 (op-amp): amplifica 40x la señal debil del cuello
- Cout (47nF): filtro paso-bajo. Corta frecuencias >3.4kHz.
  Evita aliasing: si muestreamos a 8kHz, frecuencias >4kHz se "disfrazan"
  como frecuencias bajas falsas y corrompen la señal. Cout las elimina antes.
- Rout (1kOhm): resistencia de salida, trabaja con Cout para formar filtro RC
